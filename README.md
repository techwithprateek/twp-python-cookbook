# 🐍 TWP Python Cookbook

A three-level hands-on Python for Data project series.
Each level is a fully runnable, portfolio-ready project that builds on the last.

---

## How the levels work

| Level | Project | What you learn |
|---|---|---|
| **Level 1** — Beginner | Remote Job Scraper | Python syntax, lists, dicts, loops, functions, filtering, missing values, basic charts |
| **Level 2** — Intermediate | Cohort Analysis | GroupBy, Merge/Join, Pivot Tables, Datetime, Statistical Visualizations, Data Validation |
| **Level 3** — Advanced | Customer LTV Engine | Complex Transformations, Window Functions, Pipeline Automation, Data Quality Checks, Decision-ready Insights |

---

## Quick start

```bash
# Level 1 — Remote Job Scraper
cd level-1-job-scraper
pip install -r requirements.txt
python3 main.py python        # replace 'python' with any keyword

# Level 2 — Cohort Analysis
cd level-2-cohort-analysis
pip install -r requirements.txt
python3 main.py               # runs with built-in sample data

# Level 3 — LTV Engine
cd level-3-ltv-engine
pip install -r requirements.txt
python3 main.py               # runs with built-in sample data
```

> All three projects work out of the box with no downloads required.
> Optional real datasets are described in each project's own README.
